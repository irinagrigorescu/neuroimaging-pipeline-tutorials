# Neuroimaging Pipelines: Practical Tutorials

Welcome to our group's training repository for neuroimaging pipelines.
This collection of practical tutorials is designed to take you from raw volumetric data through to advanced cortical surface analysis.

## About the Course

This repository contains a collection of practical tutorials, code snippets, and examples for neuroimaging workflows used in our research group.

## Tutorials

### Before you start

The course uses several software tools and data that needs to be installed first. Please read our [installation guide](Install.md).

### Volumetric analysis
Learn the basic image processing tools for volumetric MRI analysis.

[Open the image processing tutorial](./image_processing/imag_proc.md)

### Cortical Surfaces: Introduction, Visualisation, and Quality Control
Learn how cortical surfaces are represented, explore them in Connectome
Workbench, and assess reconstruction quality.

[Open the surfaces tutorial](./surfaces/surfaces.md)

### Statistical Analysis for Cortical Surfaces
Learn how to achieve surface registration using MSMsulc and assess registration results: [Open the MSMsulc](./surface-stats/MSMsulc_tutorial.md)

Learn how to project volume (dMRI/fMRI) data to surface using wb_command: [Open the volume2surface](./surface-stats/volume2surface.md)

Learn how to use FSL|PALM to do vertex-wise surface-based statistical analyses: [Open the PALM](./surface-stats/PALM.md)
